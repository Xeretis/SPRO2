# SDU - Electronics Semester Project 2 - ECG and blood pressure measurement device

This repository contains all files needed for a reproduction of the ECG and blood pressure measurement device built by Group ENG-4 for Electronics Semester Project 2.

- `SPRO2Hardware` includes all the KiCad and gerber files for manufacturing the PCB used for the project.
- `SPRO2Software` contains all the code for the embedded software running on the microcontroller used in the project.

For reading data exports from the device, the python script `plotter.py` has also been included. For more information on the project including the hardware and the software, please refer to the project report.
